# Capital Project Controls & Milestone Delivery KPI Dashboard

An end-to-end capital project controls and engineering deliverables analytics dashboard evaluating Earned Value Management (EVM), schedule milestones, and budget variances across multi-discipline capital engineering workflows.

---

## 📌 Dataset Validation & Scope

* **Scope:** 2,500 engineering deliverables and fabrication milestones across 5 core disciplines (Piping, Civil/Structural, Mechanical, Electrical, Instrumentation).
* **Metrics:** Budget at Completion ($BAC$), Planned Value ($PV$), Earned Value ($EV$), Actual Cost ($AC$), Schedule Performance Index ($SPI$), and Cost Performance Index ($CPI$).

---

## 🛠️ Tech Stack

* **Business Intelligence:** Microsoft Power BI (DAX measures, Star Schema Data Modeling, Drill-Down Visuals)
* **Programming & Modeling:** Python 3.10+ (Pandas, NumPy, Matplotlib)
* **Relational Database & Querying:** SQL (PostgreSQL dialect) — EVM aggregates, critical path delay analysis
* **Spreadsheet Modeling:** Advanced Microsoft Excel (Earned Value matrices, project look-ahead trackers)

---

## 📊 Key EVM Findings

* **Overall Portfolio Progress:** **57.4%** across 2,500 capital engineering deliverables.
* **Portfolio Cost Performance (CPI):** **0.961** (indicates ~3.9% aggregate cost overrun, within standard contingency).
* **Discipline Variance:** Piping & Layout accounted for 35% of total deliverables; early identification of spool fabrication delays enabled recovery scheduling 30 days ahead of field erection.
